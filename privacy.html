SOMBA Social Media Dashboard

Privacy Policy

Last updated 3 September 2026

The SOMBA Social Media Dashboard is a small internal reporting tool run by the Brand Ambassadors of the Cal Lutheran School of Management. It collects the public and owner-visible statistics for SOM's own social media accounts and shows them on one page.

In short: this tool reads our own accounts' numbers. It does not collect anything about you for visiting this site, it shows no adverts, and it sells nothing to anyone.

Information the dashboard reads

The dashboard reads statistics about social media accounts that SOM owns and operates — Instagram, TikTok, YouTube and LinkedIn. That includes:

  • Follower, subscriber, post and view counts
  • Aggregate reach, views, likes, comments, shares and saves
  • Aggregate audience breakdowns, such as age bands, gender and general location
  • Per-post statistics for posts published by these accounts

These figures describe our own accounts. The dashboard never identifies an individual viewer or follower, and no platform provides it with a way to do so.

Google user data

When an account owner grants permission, the dashboard uses the YouTube Analytics API to read statistics for the YouTube channel that person owns. It requests read-only access, and it uses that access for one purpose: to display the channel's own aggregate performance figures on this dashboard.

The dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically, data obtained from Google APIs is not sold, is not used for advertising, and is not transferred to anyone except as necessary to provide and maintain this dashboard, or where required by law.

Permission can be withdrawn at any time from your Google Account's permissions page. Once withdrawn, the dashboard stops reading new figures.

Where the numbers are kept

Collected figures are stored as aggregate numbers in this project's code repository and published on this dashboard, which is publicly reachable. Only account-level and post-level totals are stored. No login details, no message contents, no follower lists and no personal information about any individual are stored at any point.

Account credentials are held only on the maintainer's own computer and are never committed to the repository or published.

Information collected from visitors

None. This site sets no cookies, runs no analytics or tracking, and has no accounts or sign-in.

One thing is saved in your own browser: if you tick items in the growth checklist, those ticks are stored locally on your device so the page remembers them. That information stays in your browser, is never transmitted anywhere, and disappears if you clear your browsing data.

The page loads a charting library, web fonts and YouTube thumbnails from Google, jsDelivr and YouTube. Requesting those files reveals your IP address to those providers, as with any website that loads external resources.

Children

This dashboard is a reporting tool for university staff and student ambassadors. It is not directed at children and collects no information from anyone.

Changes

If this policy changes, the updated date at the top of this page changes with it.

Contact
